Ancestry classification
for 23andMe files

An open-source SDK and web app that assigns a 23andMe v5 raw-data export to the genetically most similar 1000 Genomes reference group — AFRAMREASEURSAS — using a fixed panel of 335,632 markers, 10 principal components and a frozen classifier.

Accepts .txt raw-data exports (GRCh37). Files are parsed locally with JavaScript and never leave your device. The demo is a real, anonymised v5 export bundled with the project (16 MB).

Pipeline

  1. Validate chip version, genome build (GRCh37), missing calls
  2. Encode count the REF allele (0/1/2) at each model marker; missing or incompatible → NaN
  3. Check coverage ≥ 90 % of markers called, ≤ 1 % incompatible alleles
  4. Classify ONNX in-browser: mean-fill → scale → PCA → logistic regression (also returns PC scores)

Participants, reference cohort & genotype files

The 1000 Genomes people used to train (2,003) and test (501) the classifier, with their known super-population labels (from data/reference_cohort.json); public Personal Genome Project participants with 23andMe files (data/participants_catalog.json); and any files you upload. One row per person or file. Self-reported sex, race and ethnicity come from PGP surveys and are shown separately from the predicted reference group.

      About the classifier

      The model is trained on the 1000 Genomes Phase 3 reference (2,504 people, 26 populations) and reports the super-population that is genetically most similar to the uploaded profile. It is intended as a reusable, frozen component for downstream genomics workflows such as polygenic-score imputation evaluation.

      Use it as an SDK

      npm i ancestry-classification-for-v5-23andme-files

import { classifyAncestry } from
  "ancestry-classification-for-v5-23andme-files";
const r = await classifyAncestry(fileText);
r.group;   // "EUR"
r.scores;  // { AFR, AMR, EAS, EUR, SAS }

      Interpreting results

      • Output is genetic similarity to a reference group, not an admixture proportion.
      • AMR denotes the admixed American reference populations, not an Indigenous American label.
      • Genetic group assignment is separate from self-reported race and ethnicity.
      • Files that fail input checks return a reason and no classification.
